# Changelog

## 0.1.1 — 2026-10-02

- Offline user installer, configurable prefix, verified installation candidates.
- Repeat installation, updates and managed uninstall with lifecycle tests.
- `ail doctor` environment report and `ail examples` asset discovery.
- Python wheel/source packaging with bundled examples and documentation.
- English/Russian README, AI guide, MIT license and GitHub upload instructions.
- CI matrix and release artifact workflow; local source archive builder.
- Language graph format remains version 1; the existing 20 opcodes are unchanged.

## 0.1.0 — 2026-10-02

- Typed JSON SSA graph, structure/type/effect/CFG/dominance verifier.
- Linux x86-64 assembly backend and static ELF build.
- Reference interpreter, functions, recursion, branches, block-argument loops.
- Hash-guarded graph edits, eight examples and compiler tests.
