# Проверка AIL 0.1

Обновление 0.1.1: к 41 тесту компилятора добавлены 12 проверок установщика
и диагностики. Итого **53 теста прошли локально** на Python 3.12.14.
Проверены пользовательский prefix с пробелами, повторная установка, обновление,
запуск вне исходного checkout, удаление и повторная установка, сохранение чужих
команд/каталогов, отказ от подмены symlink и изменённых установленных файлов.
Также отдельно проверены wheel в новом venv и релизный tar.gz с установщиком.
Матрица Python 3.10/3.12/3.13 настроена в CI; запуск в GitHub ещё не выполнялся.

Проверено 2 октября 2026 года в Linux x86-64, Python 3.12.14, GNU binutils.

Основной запуск:

```bash
python3 -m unittest discover -s tests -v
```

Результат: **41 тест прошёл**. Внутри них выполнены дополнительные наборы
subtests, включая 350 проверок арифметики: 14 операций × 25 пар операндов.
Случайные операнды имеют фиксированный seed 8172.

| Область | Проверки |
|---|---|
| Семантика чисел | Все 64 бита результата, signed wraparound, отрицательные значения, MIN/MAX |
| Деление | Округление к нулю, знак остатка, zero и MIN/−1 traps |
| Boolean | and/or/xor, выбор результата |
| Поток исполнения | Факториал, Fibonacci, self-loop с обменом аргументов, обе ветви условия |
| Вызовы | Рекурсия, сохранность значений после вызова, шесть register arguments |
| I/O | stdout, stderr, UTF-8, пустые globals, встроенный NUL, raw write syscall |
| ELF | Отсутствие INTERP, GNU_STACK без права исполнения |
| Структура | Неизвестные поля/opcodes, повторные JSON keys, неверные identifiers/types |
| SSA и CFG | Повторные определения, ссылки вперёд/на себя, dominance, недостижимые блоки |
| Переходы | Неизвестные цели, неверное количество и типы аргументов, запрещённый entry backedge |
| Эффекты | Необъявленный write, эффекты вызываемой функции |
| Изменения | Fingerprint conflict, rollback, замена инструкции и функции |
| Ресурсы | Ограничение шагов и глубины интерпретатора |
| Сохранение | Canonical JSON round trip, сохранение output при ошибке, защита source в CLI |

Сравнение нативного кода и интерпретатора проверяет stdout, stderr и код
завершения. В арифметических тестах дополнительно встроено сравнение результата
со всеми 64 битами ожидаемого значения, потому что Unix exit code имеет лишь
8 бит. Тесты корректных программ имеют нативный timeout 3 секунды.

Это не доказательство корректности компилятора и не проверка всех возможных
программ. Производительность, преимущества для LLM, Windows, macOS, ARM,
произвольные syscalls и работа с динамической памятью не проверялись.
